# 实施计划：连续性一致性改造（P0–P2）

目标：从"逐镜独立文生视频 + 硬切拼接"升级为"按场景条件链式生成 + 编辑端裁帧 + 接口化质检"，根治人物/服装/场景/昼夜跳变。Agnes 接口按公开文档假设（OpenAI 兼容，首帧/参考图字段可配），做成可配置以备服务器端联调校准。

---

## P0-A：分镜版本隔离（堵住新旧镜头混用）

**根因**：`agent4_storyboard.py:91` 重写时 `video_assets=[]`，但 `shots/` 目录下旧 mp4 残留 → 恢复模式新镜头与原版 s01–s09 混用。

**改动**：
- `agnes_video.py::episode_output_dir(project_id, ep_id, version=None)`：增加可选 `version`，输出 `.../{ep_id}/shots/v{N}/`。version=None 时回退当前行为（兼容已有快照）。
- `EpisodeState` 新增 `storyboard_version: int = 1`；Agent4 进入 recovery（`director_rejected`）时 `version += 1`，并显式删除上一版本 `shots/v{N-1}/` 目录后写新版本（"清空状态即清目录"对齐）。
- Agent5 下载路径改为 `shots/v{version}/{index:03d}_{shot_id}.mp4`。
- 测试：`test_storyboard_revision_isolates_shot_directories`（重写后旧目录被清、新版本独立）。

## P0-B：角色圣经真正生成 + 空表禁止渲染门禁

**根因**：`extract_characters` 只认"XX说/道：…"（characters.py:29），叙述型原文返回空；Agent3 `fallback=[]` → 空 `characters` → `render_character_block` 返回 `""` → 提示无注入。

**改动**：
- `src/characters.py` 新增 `build_character_bible(script_outline, episodes, raw_text)`：联合多源（剧本大纲、各集 outline/ending_hook、原文）用 LLM（`create_text_model`）生成结构化角色圣经；LLM 失败时回退到增强的确定性抽取（扩充模式：人物名 + "是/身份为/穿着/身披/乃"等外形/服化线索）。每集也派生该集出场角色子集。
- `CharacterSheet` 增加 `wardrobe_id: str`、`reference_image_prompt: str`、`appears_in: list[str]`（集号）。
- Agent3 调用 `build_character_bible` 写入 `state["characters"]`；各集 `EpisodeState.characters` 填入本集出场角色。
- **门禁**：`agent5_director.process_agent5_director` 入口校验：若 `state["characters"]` 为空且未设 `DRAMAMATRIX_ALLOW_NO_CHARACTERS=1`，则置 `blocked_on_missing_character_bible` 并 END（不渲染）。
- 测试：`test_character_bible_generated_from_narrative`（叙述型原文不再得空表）、`test_render_blocked_without_character_bible`。

## P1-A：ShotStoryboard 连续性字段 + end_state 归一化

**根因**：state.py:6 仅 6 字段，无 scene/wardrobe/姿态/视线/previous_shot。

**改动**（向后兼容，新字段全部 Optional + 默认值，旧快照可恢复）：
- `ShotStoryboard` 新增：`scene_id`、`location_id`、`wardrobe_ids: list[str]`、`time_of_day`、`weather`、`light_direction`、`color_temperature`、`start_pose`、`end_pose`、`subject_position`（画面位置）、`gaze_direction`、`motion_direction`、`previous_shot_id`、`transition_type`。
- 新模型 `ShotBoundaryState`（pose/position/gaze/light 子结构），`start_state`/`end_state` 用它。
- **软约束归一化**（Agent4 后处理）：遍历分镜，令 `shot[i].end_state` 被 `shot[i+1].start_state` 覆盖（以"下一镜起始"为准做对齐），并记录 `continuity_warnings`（字段缺失/冲突告警），不抛错。强相等约束会因 LLM 不稳定频繁失败，故用归一化 + 告警。
- 测试：`test_end_state_normalized_to_next_start_state`、`test_continuity_warnings_collected`。

## P1-B：create_video 支持首帧/参考图（OpenAI 兼容假设）

**根因**：agnes_video.py:322 `create_video` 仅文本 payload。

**改动**（字段名可配，便于联调校准）：
- `create_video(prompt, negative_prompt, duration, seed, image=None, image_url=None, last_frame=None, last_frame_url=None)`。
- payload 增加字段：`image`/`image_url`（首帧或参考图）、`last_frame`/`last_frame_url`（关键帧尾帧，备选）。字段名读 env（`AGNES_IMAGE_FIELD=image`、`AGNES_IMAGE_URL_FIELD=image_url`、`AGNES_LAST_FRAME_FIELD=last_frame`）默认值即公开文档假设。仅当非空才注入。
- 新增 `extract_last_frame(video_path, out_path)`（ffmpeg `-sseof -0.1` 取尾帧为 png；缺 ffmpeg 返回 None）。
- 新增首帧/参考图准备：`prepare_shot_reference(shot, scene_references)` → 返回该镜应使用的 `image_url`（按 scene_id 从 `scene_references` 取，或上一镜尾帧）。
- 测试：`test_create_video_includes_image_when_provided`、`test_create_video_omits_image_fields_when_absent`、`test_extract_last_frame_without_ffmpeg_returns_none`。

## P1-C：按场景分组 + 尾帧传递（同场景并发，跨镜串行）

**改动**（agent5 `_render_episode` 重构）：
- 第一遍按 `scene_id` 把分镜分组；为每个 scene 准备**固定参考图缓存**（首镜用角色/场景参考图，存 `scene_references/{scene_id}.png` 或其 image_url）。
- 同一场景内首镜用参考图生成，**后续镜头用上一镜尾帧**作为首帧（串行依赖：必须等上一镜下载完才能 `extract_last_frame`）。
- 同一场景不同镜头串行；不同场景可并发（本次先实现串行骨架 + 同场景参考图复用，并发作为后续优化点标注 TODO，避免一次引入线程复杂度）。
- 同场景统一 seed（`seed = base + scene_index`），不同场景不同 seed。
- 角色一致性块照旧注入；wardrobe_ids 与 scene_id 一并写入提示。
- 测试：`test_first_shot_uses_scene_reference`、`test_subsequent_shot_uses_previous_last_frame`、`test_same_scene_shares_seed`。

## P2-A：逐镜质检钩子（接口化，默认轻量）

**改动**：
- `src/continuity_qc.py`：定义 `ContinuityChecker` 接口 `check(prev_video, prev_last_frame, curr_video, shot) -> ContinuityResult(passed, issues)`。
- `DefaultChecker`：仅做轻量检查——首尾帧直方图/亮度差异阈值、人物数突变（用 ffmpeg/可选 vision，缺工具时降级为"通过 + 告警"）。
- 不合格时**只重绘当前镜头**（重新提交，受 `max_revisions` 约束），不等全部生成。
- 重模型（CLIP/InsightFace 人脸身份相似度）作为可插拔实现，默认不启用（服务器端按需接入），避免引入本地无法满足的重依赖。
- 测试：`test_failing_continuity_triggers_single_shot_redraw`、`test_qc_degrades_gracefully_without_tools`。

## P2-B：编辑端裁头尾不稳帧 + 不做统一交叉淡化

**改动**（`agnes_video.py` `concat` 流程）：
- 新增 `trim_unstable_frames(path, head=3, tail=3)`：裁掉每段开头/结尾不稳定帧（可配 `DRAMAMATRIX_TRIM_HEAD/TAIL`，默认 0=不裁以保持兼容）。
- 归一化前先 trim；拼接仍用硬切（同场景）；**不**统一加交叉淡化（避免双脸/重影）。
- 转场类型由分镜 `transition_type` 决定：同场景硬切；时空变化用短叠化（6–12 帧）/闪白，仅在边界处施加，非全局。
- 测试：`test_trim_applied_when_configured`、`test_no_global_crossfade`。

## 向后兼容与回退
- 所有新字段 Optional + 默认值；旧 SQLite 快照可正常恢复（`restore_project_state` 已能处理 dict→model，新增字段缺省即默认）。
- 首帧/参考图能力默认**关闭**（`DRAMAMATRIX_CONDITIONAL_GENERATION=0`），开启后才走尾帧传递；关闭时行为与现状一致，便于灰度。
- 角色圣经门禁默认开，但提供 `DRAMAMATRIX_ALLOW_NO_CHARACTERS=1` 逃生开关（兼容旧项目/调试）。

## 测试与验证
- 新增测试文件 `tests/test_continuity.py`（覆盖 P0-A/B、P1-A/B/C、P2-A/B）。
- 全部媒体/Agnes/ffmpeg 调用走 mock，本地无 ffmpeg 可跑绿；CI 同样可跑。
- E2E 冒烟扩展：开启条件生成后，断言"第 2 镜使用了第 1 镜尾帧"被调用一次。
- 服务器端（完整环境）实跑项在说明中标注：首帧字段名联调校准、真实视觉质检阈值。

## 优先执行顺序
P0-A → P0-B → P1-A → P1-B → P1-C → P2-A → P2-B，每步完成立即补测试并跑绿，最后统一 `pytest tests/ -q` 全绿。

## 主要风险
- **Agnes 字段名**：按公开文档假设，做成 env 可配；联调时仅需改字段名，逻辑不动。
- **串行耗时**：跨镜尾帧传递失去并发，长剧较慢；同场景参考图复用缓解，全并发留作后续优化。
- **质检重模型**：默认轻量 + 降级，不阻塞主链路。
